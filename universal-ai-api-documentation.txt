Tài liệu này cung cấp toàn bộ hướng dẫn kết nối, cơ chế xác thực an toàn, quy chuẩn yêu cầu (Request/Response) tương thích chuẩn OpenAI, và danh bạ phân loại chi tiết hơn 130 mô hình trí tuệ nhân tạo (AI) có thể gọi từ bất kỳ nền tảng nào (Terminal cURL, Web frontend, Node.js, Python, Cursor, Cline, Aider).

## 1. Thông Tin Kết Nối & Xác Thực (Authentication)

### 1.1. Các Endpoint Cốt Lõi
| Mục đích | Giao thức & Đường dẫn | Định dạng |
| :--- | :--- | :--- |
| **Chat Completions (Chuẩn OpenAI)** | `POST https://ruaxbonz.com/v1/chat/completions`<br>`POST https://ruaxbonz.com/api/v1/chat/completions` | JSON / SSE Stream |
| **Universal Chat API** | `POST https://ruaxbonz.com/api/ai/chat` | JSON |
| **Lấy danh bạ Models** | `GET https://ruaxbonz.com/v1/models`<br>`GET https://ruaxbonz.com/api/ai/models` | JSON |
| **Giao diện Playground kiểm thử** | `GET https://ruaxbonz.com/test-ai` | Web UI |

### 1.2. Cơ Chế Xác Thực Mật Khẩu (`Thangloi8030@`)
Mọi yêu cầu đến API đều bắt buộc phải cung cấp mật khẩu `Thangloi8030@`. Nếu không có hoặc nhập sai, API sẽ từ chối ngay với mã lỗi `401 Unauthorized`.

Bạn có thể truyền mật khẩu theo 1 trong 4 cách sau tùy vào thư viện hoặc công cụ sử dụng:
1. **HTTP Bearer Token (Khuyên dùng cho OpenAI SDK/Curl):**
   ```http
   Authorization: Bearer Thangloi8030@
   ```
2. **HTTP Custom Header:**
   ```http
   X-API-KEY: Thangloi8030@
   hoặc
   X-Passcode: Thangloi8030@
   ```
3. **Trong thân dữ liệu JSON (Request Body):**
   ```json
   {
     "password": "Thangloi8030@",
     "model": "deepseek-r1",
     "messages": [{"role": "user", "content": "Hello"}]
   }
   ```
4. **Tham số trên URL (Query String):**
   ```text
   https://ruaxbonz.com/api/ai/chat?key=Thangloi8030@
   ```

## 2. Quy Chuẩn Gửi Dữ Liệu (Request & Response)

### 2.1. Yêu cầu văn bản thuần túy (Text-Only Prompt)
```json
{
  "model": "deepseek-r1",
  "temperature": 0.7,
  "max_tokens": 2048,
  "messages": [
    {
      "role": "system",
      "content": "Bạn là chuyên gia cố vấn công nghệ."
    },
    {
      "role": "user",
      "content": "Giải thích thuật toán Dijkstra bằng ví dụ thực tế."
    }
  ]
}
```

### 2.2. Yêu cầu có hình ảnh (Multimodal Vision Prompt)
> [!IMPORTANT]
> Chỉ các mô hình hỗ trợ Vision (như `gemini-2.0-flash`, `gpt-4o`, `pixtral-12b`, `qwen/qwen3-vl-plus:free`) mới xử lý được ảnh. Các model như `deepseek-r1` hoặc `llama-3.3-70b` sẽ báo lỗi nếu nhận mảng `image_url`.

```json
{
  "model": "gemini-2.0-flash",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "Hãy giải bài toán trong ảnh này và chọn đáp án trắc nghiệm đúng:"
        },
        {
          "type": "image_url",
          "image_url": {
            "url": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAA..."
          }
        }
      ]
    }
  ]
}
```

## 5. Hướng Dẫn Tích Hợp Đa Nền Tảng (Code Mẫu)

### 5.1. cURL (Terminal / Bash / CMD)
```bash
curl -X POST https://ruaxbonz.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer Thangloi8030@" \
  -d '{
    "model": "deepseek-r1",
    "messages": [
      {"role": "user", "content": "Viết thuật toán sắp xếp nhanh (QuickSort) bằng Python"}
    ],
    "temperature": 0.3
  }'
```

### 5.2. JavaScript / Node.js (Fetch API)
```javascript
async function askAI(prompt, model = 'deepseek-v3') {
  const res = await fetch('https://ruaxbonz.com/api/ai/chat', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer Thangloi8030@'
    },
    body: JSON.stringify({
      model: model,
      messages: [
        { role: 'system', content: 'Bạn là chuyên viên kỹ thuật giải đáp ngắn gọn.' },
        { role: 'user', content: prompt }
      ]
    })
  });

  const data = await res.json();
  return data.choices[0].message.content;
}

askAI('So sánh ưu nhược điểm giữa Redis và Memcached').then(console.log);
```

### 5.3. Python (Thư Viện Chuẩn `openai`)
```python
from openai import OpenAI

client = OpenAI(
    base_url="https://ruaxbonz.com/v1",
    api_key="YOUR_API_KEY"
)

# 1. Gọi mô hình suy luận sâu
response = client.chat.completions.create(
    model="deepseek-r1",
    messages=[
        {"role": "user", "content": "Một người bán 100 quả táo với lãi 20%, tính giá vốn."}
    ]
)
print("DeepSeek R1:", response.choices[0].message.content)

# 2. Gọi mô hình thị giác (Vision)
vision_response = client.chat.completions.create(
    model="gemini-2.0-flash",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Mô tả hình ảnh sau:"},
                {
                    "type": "image_url",
                    "image_url": {"url": "https://example.com/sample.png"}
                }
            ]
        }
    ]
)
print("Gemini Vision:", vision_response.choices[0].message.content)
```
